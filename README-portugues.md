# RackTables REST API

O [README principal](README.md) está em português e reúne instalação, configuração, execução, autenticação, endpoints, exemplos e documentação com Zensical.

Após instalar as dependências correspondentes, use:

| Comando | Finalidade |
| --- | --- |
| `npm run dev` | Iniciar a API e o Swagger na porta 8000 |
| `npm run docs:dev` | Iniciar a documentação Zensical na porta 8001 |
| `npm run docs:build` | Gerar o site estático em `site/` e encerrar |

O Zensical inicia separadamente da API. A prévia permanece no terminal, atualiza ao salvar o Markdown e encerra com **Ctrl+C**.

Veja a [instalação e execução do Zensical](README.md#site-de-documentação) e o [guia para editar as páginas](docs/site/documentacao.md).
