## Why it was created

The RackTables REST API was created to address INPE's datacenter infrastructure management needs. Its purpose is to make it easier to query and update information about equipment, racks, physical locations, and inventory attributes over HTTP.

The API provides an integration layer for the RackTables database, allowing applications, scripts, and other tools to use this data during infrastructure monitoring and maintenance activities.

## Open source project

The RackTables REST API is an open source project available for community use and contributions. Although it was developed in the context of activities at INPE, its use is not limited to the institution: other teams can use and adapt it for their own RackTables installations.
