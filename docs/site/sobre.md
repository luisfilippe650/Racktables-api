# Sobre o projeto

**Português (Brasil)** | [English](en/about.md)

## Quem desenvolveu

Desenvolvido por **[Luis Filippe Reis Nogueira](https://github.com/luisfilippe650)** no contexto de suas atividades de estágio na **Divisão de Infraestrutura de Dados e Supercomputação (COIDS)** do **[INPE — Instituto Nacional de Pesquisas Espaciais](https://www.gov.br/inpe/pt-br)**.

O código-fonte está em [luisfilippe650/Racktables-api](https://github.com/luisfilippe650/Racktables-api).

## Por que foi feito

A RackTables REST API foi criada a partir das necessidades de gerenciamento da infraestrutura de datacenter do INPE. Seu objetivo é facilitar a consulta e a atualização das informações de equipamentos, racks, locais físicos e atributos do inventário por HTTP.

A API fornece uma camada de integração com o banco de dados do RackTables, permitindo que aplicativos, scripts e outras ferramentas utilizem esses dados nas atividades de acompanhamento e manutenção da infraestrutura.

## Projeto aberto

A RackTables REST API é um projeto open source, aberto para uso e contribuição pela comunidade. Embora tenha sido desenvolvido no contexto das atividades no INPE, seu uso não se limita à instituição: outras equipes podem utilizá-lo e adaptá-lo às suas instalações do RackTables.

## Créditos e integração com o RackTables

Os créditos pelo RackTables pertencem à sua **comunidade e aos seus mantenedores**.

- [Site do RackTables](https://www.racktables.org/)
- [Código-fonte do RackTables](https://github.com/RackTables/racktables)

A RackTables REST API é um projeto independente e não é uma API oficial do RackTables. O RackTables e as bibliotecas de terceiros mantêm suas respectivas licenças e créditos.
